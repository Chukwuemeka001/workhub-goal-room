# Phase 7 competition requirements

**Live verification date:** 2026-08-27

**Official deadline:** September 3, 2026 at 1:00 PM Pacific Time.[1]

**Internal submit target:** September 2, 2026 at 12:00 PM Pacific Time.

## Required entry materials

The entry must provide all of the following:

1. A working live URL accessible in ChatGPT's in-app browser or Google Chrome with WebMCP enabled.[1]
2. A text description explaining why this use case fits WebMCP, how it improves user experience, what people and agents can do together that was previously difficult or impossible, and how WebMCP was implemented.[1]
3. A public repository containing all necessary source code, assets, and run instructions, with an open-source license visible on the repository page.[1]
4. A public YouTube demonstration video under three minutes, with audio, clearly showing the functioning project and how it uses WebMCP.[1]
5. Free, unrestricted judge access through the end of the judging period.[1]
6. English-language submission materials.[1]

The submitted project must function as depicted in the video and text. If it extends pre-existing work, the entry must distinguish prior work from WebMCP work added after the submission period opened, using dated commits or equivalent evidence.[1]

## Judging model

Stage one is pass/fail for theme fit, baseline viability, and meaningful use of the required technology. Stage two weights four criteria equally:[1]

- **WebMCP Leverage:** thorough, skilful, working, non-trivial use of WebMCP.
- **Execution:** a coherent runnable product, not only a technical proof.
- **Potential Impact:** a credible specific problem, audience, and demonstrated solution.
- **Creativity & Ambition:** novelty and differentiation.

WebMCP Leverage is the first tie-break criterion.[1]
